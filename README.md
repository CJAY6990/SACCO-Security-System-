The adoption of mobile loan applications by SACCOs has improved service delivery but has also increased exposure to cybersecurity threats, particularly API vulnerabilities such as Insecure Direct Object Reference (IDOR). These vulnerabilities can allow unauthorized users to access sensitive member information, including loan records, guarantor details, and personal data. Since SACCOs handle confidential financial information, securing these systems is essential to protect member privacy, maintain trust, and comply with the Kenya Data Protection Act (2019). This project  focuses on identifying and mitigating IDOR vulnerabilities through secure authentication, authorization, and access control mechanisms. The project will  also help strengthen API security, reduce the risk of data breaches, and provide practical recommendations for improving the security of SACCO mobile loan systems. Ultimately, the study contributes to enhanced cybersecurity, regulatory compliance, and the protection of members’ confidential information
